## 实现范围

### P01-T01 实体与固定数据

- `backend/app/contracts/domain.py`：Part、Supplier、Quote、Inventory、SourceRef、OrderItem/PurchaseOrderItem、OrderDraft、PurchaseOrder、补货请求与预览模型。
- `fixtures/v1/`：6 零件、3 供应商、8 报价、8 库存、2 历史草稿、2 历史订单；`manifest.json` 含计数、按仓库汇总、全量汇总和 canonical SHA256。
- `scripts/seed.py` + `services/seeding.py`：Pydantic 校验、外键/唯一键/金额/订单草稿一致性校验、manifest 校验、幂等 upsert；`--reset` 仅限 `technologyagent_test_*`。
- 默认 seed 不删除已有用户订单；测试插入 `O-CUSTOM` 后再次 seed 仍存在。

### P01-T02 查询仓储层

- `repositories/catalog.py`、`inventory.py`：筛选、分页、详情、范围读取；count 与 records 使用同一 filter；固定按 `_id` 排序。
- 非法 page/page_size 返回 422；未知 part/supplier ID 返回 404；空结果返回 200 + 空列表。
- `GET /api/parts、/suppliers、/quotes、/inventory、/inventory/warnings、/inventory/summary`。

### P01-T03 补货规则

- `domain/money.py`：整数分 `line_total`，拒绝 bool/负数/非整数/零单价。
- `domain/replenishment.py`：available、projected、shortage、warning；报价过滤 supplier active → valid_until>now → max_lead_days；排序 price/lead/supplier_id/quote_id；MOQ 是下限不是包装倍数。
- 无有效报价返回 `missing_fields=["valid_quote"]`、quantity/total=0、actionable=false；无缺口返回 quantity=0、recommended=None。

### P01-T04 HTTP 预览与类型生成

- `POST /api/replenishment/preview` 返回 lines、snapshot_versions、SourceRef；每响应含 meta `data_source=local_seed`、`scope=shared_catalog`、as_of。
- `scripts/export_contracts.py` 生成稳定排序的 `backend/app/contracts/domain-schema.v1.json` 与 `frontend/src/lib/domain-types.ts`；`--check` 检测漂移。
- 生成类型不在前端手写第二套实体/金额/状态。

### P01-T05 数据浏览页面

- `frontend/src/app/data/page.tsx` 与 `components/data/`：库存、供应商、报价、补货预览四类视图；仓库/物料名称筛选；库存分页；数据源/as_of 标签。
- 改仓库或物料名称时 page 重置 1；请求失败清空旧数据/金额并显示真实 API 错误；表格内部滚动，页面主体无横向溢出。
- 预览只调用 API，不在浏览器计算补货公式；`actionable=false` 明确不可下单。

### P01-T06 回归与交付

- `verify_stage P01 --mode offline` manifest：P00 必要检查 + seed + unit + integration + contract + 前端检查。
- 新增单元测试 25 条、集成测试 49 条、前端测试 4 条；模块 README 已补。
