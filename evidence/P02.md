## 实现范围

### P02-T01 事件协议

- `contracts/events.py`：12 类事件与 payload 模型；`EventEnvelope(schema_version=1,type,event_id,seq,thread_id,run_id,at,payload)`，seq>=1、UTC、payload 按类型校验。
- `contracts/agent.py`：ExecutorInput/ExecutionOutcome；`ports/executor.py`：AgentExecutor/EventSink Protocol。
- `fixtures/events/v1.json` 覆盖全部事件类型；`scripts/export_contracts.py` 生成 `contracts/events-schema.v1.json` 与 `frontend/src/lib/events.ts`，`--check` 同时检查领域与事件产物。
- 时间/seq/未知类型/未知 status/工具 call_id 配对有单测。

### P02-T02 Run/Message/Event 持久化

- `repositories/{runs,messages}.py`、`services/runs.py`；新增 threads/runs/messages/events collection 与唯一索引：
  - `(owner_id,request_id)` 唯一；`(run_id,seq)` 唯一；thread 活跃 run 通过事务认领。
- 创建事务：认领/新建 thread、建 run、保存 user message；同 request_id 同 payload 返回原 run，不同 payload 409。
- append_event：事务内 `$inc last_seq` + 插入事件，seq 1..N 连续；10 并发 append 测试无断档。
- finish：最终 assistant 固定 message_id、run_finished、stream_end、run 状态、thread 释放同一事务；重复 finish 不重复消息/事件。
- 真实 Mongo 事务 transient write conflict 加 per-run asyncio lock + 有界重试；测试用真 replica set。

### P02-T03 FakeAgent 与 SSE

- `agent/fake_executor.py`：固定示例文本分块 token、fake 只读工具 call、`simulation=true`，每步检查取消/deadline；工具失败路径抛错。
- `services/chat.py`：进程级 ChatTaskManager 强引用；后台任务独立于 HTTP 观察连接；断流不取消。
- `api/chat.py`：`POST /api/chat/stream` 先启动 run 再返回 SSE；首事件 run_started，末事件 stream_end；每 50ms 读取持久事件。
- Next rewrite 会缓冲 SSE（实测 6KB 一次到），新增 `frontend/src/app/api/chat/stream/route.ts` 反向代理并直接返回 `ReadableStream`，浏览器恢复增量（约 200ms/块）。

### P02-T04 历史、重放、取消、重启

- `api/history.py`：会话列表/详情/删除；运行中删除 409；删除事务清理 messages/events/runs/thread。
- `api/runs.py`：run 查询、events?after_seq、cancel；cancel 写 cancel_requested 并通知执行器，不用断开 HTTP 连接实现。
- 启动时 `RunService.recover_orphans()` 将遗留 created/running 标 failed/PROCESS_RESTARTED，写 error/run_finished/stream_end 并释放 thread；P02 无检查点，不宣称恢复。
- owner 条件进入所有 DB 查询；跨 owner 的 run/conversation/events 返回 404。

### P02-T05 前端解析与聊天页

- `lib/sse-parser.ts`：TextDecoder(stream) 跨 chunk、CRLF、注释心跳、data 多行、末尾不完整帧抛错；schema_version!=1 抛不兼容；未知兼容 type 交 reducer 忽略。
- `lib/event-reducer.ts`：run+seq 去重、token 按 message_id 合并、工具卡片配对、历史最终消息按 id 替换 token 内容。
- `hooks/{useSSE,useHistory,useChat}.ts`、`components/chat/*`、`components/sidebar/ConversationList.tsx`、`/chat` 页面；FakeAgent 标识、历史、刷新恢复、2 秒轮询、停止、切换会话。
- 本地会话在进入聊天/发送前 ensureLocalSession；刷新 URL 带 thread 参数。

### P02-T06 验收与交付

- E2E `tests/e2e/chat-flow.spec.ts` 4 用例：发送/工具卡/刷新去重、运行中刷新恢复、停止、切换会话。
- 页面显示 FakeAgent/model_mode=fake；证据不把 fake 写成真实模型。
