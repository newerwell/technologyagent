## 修改（`backend/app/agent/fact_checks.py`）

- 表格先建立列角色（实体/报价、字段、值、单位）；三列或四列纵表从本行字段单元格取字段，"值/内容"不被当业务字段；单位列补 `unit_hint`。
- 实体列保留 P/W/S/Q，但只有纯 ID 单元格才整体绑定；单元格含正文时退回原有的 P/W 行扫描，避免把多个供应商都授权给同一数字。
- 普通文本在句内做受控逗号继承：只有前一分句有实体且其间没有新业务数字时才继承；句号/转折/新块清除。`数量 55，单位 套` 这类紧邻单位分句只绑定同一数量。
- Markdown 粗体/反引号按展示符号处理，单元解析前剥离前缀标记，不改动原片段偏移。
- 字段选择改为"离数字最近的标签优先"（先前向、再后向），避免 `单价11元 / 总额605元` 被右端标签覆盖。
- 保留 `BusinessClaim`/`validate_answer` 公开签名；无法唯一绑定时仍返回可修订错误，不增加"任何数值出现过就通过"的兜底。
