# 采购分析报告

目标：把已成功只读查询的数据整理成带范围、来源、观察时间的分析或报告。

何时使用：用户要求趋势分析、图表或报告。何时不用：业务事实尚未查询或用户只要求简单单值查询。

输入：当前run授权的数据集和完整用户约束。输出：报告/图表产物及关联来源，不额外推导业务结论。

规则：报告用 `artifact_report`；图表或代码分析只允许在 analyst 专家调用 `artifact_chart` / `analysis_execute`。禁止宿主代码执行、网络访问、跨run数据引用。采购补货报告逐项说明用户指定的仓库/物料、来源与观察时间；只使用实际返回的可用量、预计量、目标缺口、安全预警和目标库存字段解释补货需求。报价需比较有效状态、交期、单价和服务端总额，明确符合交期上限的推荐及因超期而排除的较低价选择。不得将分析报告写成订单已提交或已获批准。

数据不足时说明范围和缺口；不得生成空报告并称已分析。

示例：先成功查询库存，再将该数据集交给 `artifact_report` 生成JSON或HTML报告。
