# 供应商比较

目标：按当前有效报价比较供应商，不把偏好解释为有效性。

何时使用：用户询问报价、供应商或推荐。何时不用：只查询某仓库库存。

输入：零件、可选交期上限与用户明确条件。输出：具名供应商及服务端有效报价、交期、金额、来源和观察时间。

规则：使用 `quote_list` 或 `replenishment_preview`；供应商停用、报价过期或不满足本轮交期上限时不得推荐。显式偏好不能改变这些判定。

缺少零件时先澄清；同价并列时如实列出，不自行编造排序标准。

示例：7天内交货时先把 `max_lead_days=7` 传给预览，再仅比较有效结果。
